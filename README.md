# VoicingFour

Four-bar live piano/guitar voicing desk for bedroom producers and AI-music finishers.

Live FluidR3 chairs lock rhythmic comps to your 4-chord progression so the harmonic bed finally has motion.

Distinct from CompFour (static blocks), WalkFour (bass walks), StabFour (horn stabs), FigureFour (melodic lines).

## Features
- User BPM (60–180) and 4-chord entry
- Recipes: block, arp, rhythmic, jazz
- Chairs: Piano, Nylon, Steel (FluidR3, pinned SHA)
- Lookahead scheduler on AudioContext clock
- localStorage persistence
- Export stubs for WAV/MIDI (full DAW-ready in next pass)
